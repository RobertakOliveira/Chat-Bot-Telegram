# Bem-vindo ao Oráculo OABot

O **Oráculo OABot** é um assistente jurídico alimentado por Inteligência Artificial que utiliza técnicas de *Retrieval-Augmented Generation (RAG)* para consultas jurídicas inteligentes.

## Sobre o Projeto

Este projeto combina tecnologias avançadas como **LangChain**, **AWS Lambda**, e **Telegram** para criar uma experiência de consulta jurídica eficiente e amigável.
